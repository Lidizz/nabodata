# Mobile UI kit — Nabodata native (Expo / RN feel)

Click-thru recreation of the mobile experience inside an iOS frame.

- Full-screen Norway map
- Bottom sheet (peek → half → full) with stat cards, age pyramid, bars, POI chips
- Top chrome: search pill, theme switcher
- Drag the sheet handle (or tap) to switch snap heights

⚠ The map geometry is the same stylized abstraction as `ui_kits/web/Map.jsx`. Replace with MapLibre-RN or react-native-maps in production.
